# Extract Fanfic Metadata 1.2.1

Extract EPUB Metadata is now **Extract Fanfic Metadata**, because it also reads TXT
and AO3 PDF files. The name is the only change; metadata recovery works as it did in 1.2.0.

## Install

Download **extract_fanfic_metadata-v1.2.1.zip** under Assets. In Calibre, open
**Preferences → Plugins → Load plugin from file**, select the ZIP, then restart.

## If you have the old name installed

Calibre sees the new name as a separate plugin, so it will not update the old one
for you. After installing, open **Preferences → Plugins**, select
**Extract Epub Metadata**, click **Remove plugin**, then restart. Your settings and
toolbar button are kept.

## Notes

- Requires Calibre 6.0 or newer. Checked on Calibre 9.15 for macOS. Windows and Linux
  were not rechecked.
